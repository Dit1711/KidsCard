- **Дата сверки:** 2026-06-04

## Сводка: Must-пробелы, блокирующие «MVP по ТЗ»
По порядку приоритетов ТЗ (раздел 10): сначала безопасность/комплаенс, затем ядро.

1. **AML-мониторинг (правила + алерты)** (FR-KYC-03, UC-17) — 🟡 реализовано в коде (`compliance-service`), ожидает деплоя; санкции/PEP-скрининг и отчётность регулятору ❌.
2. **Аудит-логи** действий над деньгами/данными (7.2) — 🟡 реализовано в коде (append-only + hash-chain), ожидает деплоя.
3. **Реальный KYC** (документ + liveness + провайдер) — 🟡 каркас.
4. **Open Banking с реальным банком** (AIS/PIS, согласия) — 🟡 только мок.
5. **SMS-уведомления** (OTP, критичные события) — ❌.
6. **Локализация uz/ru/en** — ✅ весь UI + контент на 3 языках (серверные шаблоны уведомлений — отдельно).
7. **Reconciliation + circuit breaker/retry + Saga** (устойчивость) — 🟡/❌.
8. **Observability** (экспонировать метрики, трейсинг, дашборды) — ✅ Prometheus + Grafana + Tempo + алерты (`docs/OBSERVABILITY.md`).

## Что уже реально работает (сильные стороны)
- Ядро карт: выпуск, несколько карт, блок/разблок/заморозка/закрытие.
- Платежи: **двойная запись (ledger)**, холды, переводы (карта→карта, выплата), диспуты, идемпотентность.
- Лимиты (день/неделя/месяц/категория), мгновенные уведомления (push).

## 11. Продуктовый бэклог — новые инициативы (сверх ТЗ)

Фичи сверх исходного ТЗ. Прорабатываются совместно; решения фиксируются здесь по
мере обсуждения. Оценка: S/M/L/XL. Статус: 🅿️ в проработке · 🟢 в работе · ✅ готово.

### EPIC-1 · «Где мой ребёнок» — геолокация 🟢 (1A готов, код; ждёт деплоя)
Делится на две разные возможности:
- **1A. Карта трат** (где потрачены деньги) — данные мерчанта уже есть; добавить гео
  + экран карты. **M**, риск низкий. *Связь с ТЗ: PC-03 «Гео-ограничения» (Should).*
- **1B. Живой GPS ребёнка** — браузер не отслеживает в фоне → нужен **мобильный
  клиент**; слежка за несовершеннолетним = серьёзная **юр./приватность** (ЗРУ-547,
  согласие). **XL**, риск высокий. Отдельный эпик «мобильное приложение».
- **✅ Решение:** старт = **Вариант А** — карта трат + «последнее известное место»
  (разовая геопозиция при открытии приложения, с согласия ребёнка). Непрерывный
  GPS — в будущий эпик «мобильное приложение». Геоданные подключить к **PC-03
  (гео-ограничения)**: зоны + алерт «трата/был вне разрешённой зоны».

### EPIC-2 · Задания с фото-приёмкой ✅ (код готов; ждёт деплоя)
Флаг «нужно фото» на задании; ребёнок прикладывает фото при сдаче; родитель видит
при приёмке. Нужен **объектный сторадж** (в стеке нет — добавить MinIO/S3). **M**,
риск низкий. *Связь с ТЗ: ALW-03/04 (задания и приёмка).*
- **✅ Решение:** сторадж — **MinIO на своём сервере** (данные в РУз). Авто-удаление
  фото через **30 дней** после приёмки; на родительском окне — кнопка «сохранить
  себе» (скачать на память). ИИ-предпроверку фото пока не закладываем.

### EPIC-3 · Редизайн оформления карт — детские темы ✅ (код + 14 иллюстраций)
Тематические картинки по возрасту/полу (динозавры, монстрики, космос…).
- **⚠️ IP:** бренды (Minecraft и т.п.) — торговые марки, только **оригинальный** арт.
- **Узкое место — источник арта**, не код: ИИ-генерация / дизайнер / royalty-free.
- Тех: тема карты = **растровый фон-картинка** + scrim для читаемости текста +
  категории; обновить `CardSurface`/`cardThemes`, пикер, превью. **M**.
- **✅ Решение:** арт — **детальные растровые картинки**, которые генерит сам
  пользователь на **DALL·E** и передаёт, я встраиваю. Требования к ассетам:
  landscape ~1792×1024, единый стиль, без брендов/текста/логотипов, спокойная
  нижняя зона под текст карты. Категории по тематике; пол — нейтрально/по теме.

### EPIC-4 · ИИ-помощник в детском приложении ✅ ⭐ (готово, до миграции)
Сократический «репетитор» — подсказки, не ответы; фото задачки → разбор по шагам.
На **Claude API** (`ai-service` + чат-UI). **L–XL**, ценность высокая (дифференциатор).
- **✅ Реализовано (`ai-service`, 9-й микросервис):**
  - Чат-репетитор «Кай» (uz/ru/en), сократический метод, Markdown-ответы, треды/темы.
  - **📷 Фото задачки** — ребёнок шлёт фото (камера на телефоне), Claude vision
    разбирает по шагам; фото сжимается на клиенте, не сохраняется (приватность/цена).
  - **🎚️ Родительские настройки** — вкл/выкл репетитора по ребёнку (= согласие) +
    настраиваемый дневной лимит. Кабинет родителя → «ИИ-помощник».
  - **👀 Видимость родителю** — родитель читает переписку ребёнка (треды/сообщения);
    каждый запрос пере-проверяет родство через family-service (fail-closed).
  - **⭐ XP за учебные сессии** — реальный диалог = study-session (1/день/ребёнок,
    уникальный ключ от фарма) → деривированный XP + стрик + бейдж «Любознатель».
- **✅ Решения:**
  - **Объём MVP:** репетитор по урокам + вопросы про деньги + сильная педагогика
    (сократический метод, по возрасту, начисление XP/звёзд за учебные сессии).
  - **Видимость родителю:** включена (история чата у родителя; ребёнок знает).
  - **Приватность/ЗРУ-547:** старт на Claude API **под явным согласием родителя** +
    минимизация PII (шлём только вопрос/фото задачки, без имени/финданных).
