# Запуск проекта на своём компьютере (для теста)

Всё приложение поднимается у тебя локально одной командой через Docker.
Никакого сервера и интернета не нужно — открываешь в браузере `localhost`.

## Что нужно
- **Docker Desktop** (Mac или Windows): https://www.docker.com/products/docker-desktop/
  После установки запусти его и дай ему **минимум 6–8 ГБ памяти**
  (Docker Desktop → Settings → Resources → Memory). Стек тяжёлый: 7 сервисов + база.
- Компьютер с **8 ГБ ОЗУ — впритык, 16 ГБ — комфортно**.

## Шаги
1. **Скачай проект**: на странице репозитория GitHub → зелёная кнопка **Code → Download ZIP**.
   Распакуй архив (получится папка `KidsCard`).
2. Открой **терминал** (Mac: Terminal; Windows: PowerShell) и перейди в папку:
   ```bash
   cd путь/к/KidsCard
   ```
3. Запусти всё одной командой:
   ```bash
   docker compose -f docker-compose.local.yml up --build
   ```
   **Первый запуск долгий — 5–10 минут** (собираются сервисы). Дальше будет быстро.
4. Когда в логах всё поднимется, открой в браузере:
   **http://localhost:3000**

## Как войти (тестовый режим)
SMS не приходит — код фиксированный:
- **Родитель:** зарегистрируй любой номер вида `+998901234567`, код из SMS смотри
  в окне терминала в логах `auth-service` (строка с `OTP`), либо используй
  заранее заведённый тестовый аккаунт, если база уже с данными.
- **Ребёнок:** «Вход для детей» — код и PIN выдаёт родитель в приложении
  (раздел «Семья» → ребёнок → доступ).

## Остановить / снова запустить
- Остановить: в терминале нажми **Ctrl+C**, затем
  ```bash
  docker compose -f docker-compose.local.yml down
  ```
  (данные сохраняются — в следующий раз всё на месте).
- Запустить снова (уже без долгой сборки):
  ```bash
  docker compose -f docker-compose.local.yml up
  ```

## Если тяжело идёт
- Увеличь память Docker Desktop (Settings → Resources → Memory) до 8 ГБ.
- Закрой другие тяжёлые программы на время теста.
