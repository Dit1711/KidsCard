# KidsCard — семейный финтех для Узбекистана

Платформа, которая позволяет родителям выпускать виртуальные карты детям (6–17 лет),
управлять лимитами, карманными деньгами, поручениями и накоплениями — поверх
мульти-банковского слоя Open Banking (AIS/PIS), а не одного банка.

> Регуляторный контекст: ЦБ РУз, Закон о ПДн (ЗРУ-547), локализация данных, PCI DSS
> (PAN не хранится), KYC. NSM = Weekly Active Families.

---

## Архитектура

Микросервисы на **Kotlin + Spring Boot 3.4** (Java 21), Gradle multi-project.
Обмен событиями — **Kafka** по паттерну **transactional outbox**. Деньги —
**двойная запись** в ledger (payment-service). Веб — **Next.js 16** (App Router).

| Сервис | Порт | Отвечает за |
|---|---|---|
| auth-service | 8081 | OTP-вход родителя, JWT, refresh, вход ребёнка (код + PIN) |
| family-service | 8082 | Семья, родители/роли, дети, лимиты, цели, поручения, уроки, запросы |
| card-service | 8083 | Выпуск/заморозка карт, карманные |
| payment-service | 8084 | Ledger (двойная запись), баланс, покупки, эскроу-кошелёк, аналитика |
| open-banking-service | 8085 | Привязка счетов (AIS) и пополнение карт (PIS), песочница |
| notification-service | 8086 | Лента уведомлений + **Web Push** (VAPID) |
| kyc-service | 8087 | Верификация личности родителя |
| api-gateway | — | Заготовка (не подключён) |

Инфраструктура (`docker-compose.yml`): PostgreSQL, Redis, Kafka + Zookeeper, Kafka-UI, MailHog.

Веб-приложение проксирует сервисы напрямую (`localhost:808x`); фронтенд хранит
родительский и детский JWT раздельно в localStorage.

## Возможности

**Родитель (веб-дашборд):**
- KYC-онбординг, создание семьи, выпуск карт детям
- **Роли**: владелец (Owner) и со-родитель — приглашение по номеру телефона
- **Лимиты** трат: дневной/недельный/месячный + по категориям (MCC)
- **Карманные** деньги по расписанию (авто-начисление через Kafka)
- **Поручения** с гарантированной наградой (эскроу-кошелёк) и **повтором** (ежедн./еженед.)
- **Цели накопления** детей + дарение из кошелька; счёт начисляет **проценты**
- **Аналитика**: траты по категориям, динамика по дням, прогресс целей/заданий
- **Запросы** от детей (пополнение/повышение лимита) с одобрением
- **Уведомления**: лента + push на телефон (покупки, лимиты, задания, запросы)
- Open Banking: привязка банковских счетов и пополнение карт

**Ребёнок (мобильный кабинет):**
- Вход по коду + PIN (долгоживущая сессия)
- Карта и баланс, свои лимиты (наглядные прогресс-бары)
- 🛍️ Магазин — траты в рамках лимитов
- 🎯 Задания — выполнил → родитель подтвердил → деньги на карте
- 🐷 Цели — накопления с процентом
- 🎓 Учёба — уроки финграмотности + квизы, звёзды и бейджи
- 💌 Запросы родителю (пополнение/лимит)

## Запуск (локально)

Требуется JDK 21, Node 20+, Docker.

```bash
# 1. Инфраструктура
docker compose up -d            # postgres, redis, kafka, ...

# 2. Сервисы (каждый в своём терминале, Flyway применит миграции на старте)
./gradlew :services:auth-service:bootRun
./gradlew :services:family-service:bootRun
./gradlew :services:card-service:bootRun
./gradlew :services:payment-service:bootRun
./gradlew :services:open-banking-service:bootRun
./gradlew :services:notification-service:bootRun
./gradlew :services:kyc-service:bootRun

# 3. Веб
cd web && npm install && npm run dev    # http://localhost:3000
```

Тестовые данные для разработки (dev):
- Родитель: `+998909914927`, OTP/код из SMS: `123456`
- Ребёнок «Исик»: логин-код `H4TMUU`, PIN `1234`

## Технические заметки

- **Outbox**: продюсеры через `JsonSerializer` двойно кодируют уже сериализованный
  payload; консьюмеры разворачивают текстовый JSON. `eventType` лежит **внутри** payload.
- **Эскроу**: награда за задание резервируется (`holds`) при создании и захватывается
  при одобрении — обещанная награда всегда обеспечена.
- **Сессии**: родитель — короткий access-token (15 мин) + refresh; ребёнок —
  долгоживущий токен (низкопривилегированная сессия на своём устройстве).
- **Web Push**: VAPID-ключи в конфиге notification-service (переопределяются env);
  service worker в `web/public/sw.js`.
